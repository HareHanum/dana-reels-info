Dana Reels Agent

Dana Reels Agent הוא כלי אישי המופעל במק של הראל לצורך הכנת סרטונים קצרים מתוך הקלטות ההדרכה של דנה. דנה מעלה הקלטה לתיקיית Google Drive הייעודית; הכלי מתמלל ומנתח את ההקלטה, בוחר קטעים עצמאיים ומכין סרטונים באורך של עד 60 שניות עם כתוביות בעברית. מספר הסרטונים תלוי בתוכן ובתוצאות בדיקות האיכות.

עיבוד הווידאו והעריכה מתבצעים במק. טקסט מתמלולי ההקלטות נשלח ל־OpenAI API לצורך בחירת קטעים ובדיקת טקסט. כאשר התמלול המקומי אינו ברור, קטעי אודיו של עד 60 שניות עשויים להישלח ל־OpenAI API לתמלול נוסף, במסגרת תקציב מוגבל. קטעים אלה יכולים לכלול את קולות הדוברים בהקלטה, לרבות משתתפים בהדרכה. הווידאו עצמו אינו נשלח ל־OpenAI. הסתרת פרטים מזהים בטקסט אינה מסירה פרטים שנשמעים באודיו. הטיפול בנתונים אצל הספק כפוף להגדרות החשבון ולמדיניות OpenAI API; אין כאן הבטחה לאפס שמירת מידע. קטע לא ודאי נעצר לבדיקה.

השימוש מוגבל למפעיל ולדנה; אין הרשמה לציבור. עמוד זה אינו מאפשר העלאת הקלטות, התחברות או צפייה בסרטונים. השירות המקומי קולט הקלטות ומוסר תוצרים שעברו את הבדיקות. דנה יכולה להשיב למייל המסירה עם אישור או הערות. בקשות מזוהות לשינוי כתוביות, גודל ומיקום טקסט, צבע המילה הפעילה, זום עדין או חיתוך קצוות מטופלות אוטומטית לאחר בדיקות. כשחסר פרט, הכלי מבקש מדנה הבהרה במייל. הוראות העריכה והכתוביות הרלוונטיות עשויות להישלח ל־OpenAI API לתכנון השינוי ולבדיקות טקסט. בקשות אחרות או תקלות שאינן נפתרות דורשות את המפעיל. ההפעלה תלויה במק פועל, בחיבור לרשת ובהרשאות תקפות.
